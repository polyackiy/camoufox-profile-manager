# Camoufox Profile Manager

[![CI](https://github.com/polyackiy/camoufox-profile-manager/actions/workflows/ci.yml/badge.svg)](https://github.com/polyackiy/camoufox-profile-manager/actions/workflows/ci.yml)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Camoufox 152](https://img.shields.io/badge/camoufox-152-orange.svg)](https://github.com/daijro/camoufox)

Self-hosted менеджер профилей антидетект-браузера
[Camoufox](https://github.com/daijro/camoufox) с открытым исходным кодом —
бесплатная альтернатива AdsPower, Dolphin, Multilogin и GoLogin для тех, кто
предпочитает держать всё у себя.

Каждый профиль — **одна долгоживущая машина**. Он сохраняет один и тот же
отпечаток от запуска к запуску вместе со своими куками, хранилищем и историей,
так что аккаунт, открытый с него в январе, в июне выглядит с того же компьютера.

> **Статус:** ранний релиз (`v0.1.1`). Ядро работает и покрыто тестами, которые
> гоняют настоящий браузер; до `1.0` возможны шероховатости и изменения API.

![Веб-интерфейс Camoufox Profile Manager](docs/assets/screenshot-profiles.png)

## Что умеет

- **Профиль — одна и та же машина при каждом запуске.** Camoufox генерирует
  новый отпечаток при каждом старте: для инструмента приватности это правильно,
  для долгоживущего аккаунта — наоборот. Первый запуск разрешает отпечаток один
  раз и сохраняет его, все последующие его воспроизводят. Геолокация, таймзона и
  WebRTC остаются динамическими и следуют за прокси.
- **Отпечатки реальных устройств** — профиль можно создать из одного из 312
  слепков, снятых Camoufox с настоящих машин, а не из синтетического набора.
- **Профили и группы** — создание, правка, клонирование, удаление, поиск,
  фильтры, массовые операции и группировка по клиенту или назначению.
- **Управление браузером** — запуск и остановка по профилю; если вы закрыли окно
  сами, приложение это замечает и убирает сессию.
- **Прокси** — HTTP, HTTPS и SOCKS; пароли шифруются при хранении, если задан
  `CPM_SECRET_KEY`.
- **Перенос профиля куда угодно** — экспорт профиля вместе с отпечатком *и*
  данными браузера в один архив и импорт на другой машине.
- **Массовое редактирование через Excel**.
- **REST API и веб-интерфейс** на одном порту в одном процессе.
- **Опциональная миграция из Chrome** — импорт куков и истории из ваших
  собственных профилей Chrome.

## Установка и запуск

Нужны [uv](https://docs.astral.sh/uv/) и Python 3.10+. Node.js 20+ нужен только
если собираете веб-интерфейс сами.

### Из релиза (без Node.js)

```bash
pip install <ссылка-на-wheel-из-релизов>
camoufox fetch     # скачивает браузер, ~300 МБ, только первый раз
camoufox-pm        # API и интерфейс на http://localhost:8000
```

### Из исходников

```bash
git clone https://github.com/polyackiy/camoufox-profile-manager.git
cd camoufox-profile-manager
uv sync
uv run camoufox fetch
uv run python scripts/build_webui.py    # сборка интерфейса в пакет (нужен Node)
uv run camoufox-pm
```

### Как десктопное окно

```bash
uv sync --extra desktop
uv run camoufox-pm --desktop
```

### Через Docker

```bash
docker compose up      # затем откройте http://localhost:3000
```

Порты публикуются только на loopback.

## Первые шаги

1. Откройте приложение и нажмите **New profile**.
2. Выберите операционную систему и, при желании, **реальное устройство**, к
   которому профиль будет привязан. Оставьте поля отпечатка пустыми — Camoufox
   сгенерирует согласованный набор.
3. Добавьте прокси, если он есть. Для прокси с логином и паролем берите
   HTTP/HTTPS: Firefox не умеет аутентификацию на SOCKS-прокси.
4. Нажмите **Run**.

Экран **Settings** показывает, как настроен инстанс, и предупреждает, если пароли
прокси не зашифрованы или API доступен без ключа.

## Конфигурация

Настройки берутся из переменных окружения с префиксом `CPM_`. Скопируйте
`.env.example` в `.env` и отредактируйте. Полная таблица — в
[английском README](README.md#configuration).
