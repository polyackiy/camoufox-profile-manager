# Начало работы

[English](getting-started.md)

## Скачать и открыть

Откройте [страницу релизов](https://github.com/polyackiy/camoufox-profile-manager/releases)
и выберите установщик в разделе **Assets**. Для готового приложения не нужны
Python, Node.js и терминал. Установщики собираются автоматически для новых
релизов; в старых релизах могут быть только Python-пакеты.

| Компьютер | Файл | Установка |
| --- | --- | --- |
| Mac с Apple Silicon (M1 и новее) | `camoufox-pm-macos-arm64.dmg` | Откройте образ, перенесите приложение в Applications и запустите оттуда. |
| Mac с Intel | `camoufox-pm-macos-x86_64.dmg` | Откройте образ, перенесите приложение в Applications и запустите оттуда. |
| Windows 10/11, Intel/AMD 64 бит | `camoufox-pm-windows-x86_64-setup.exe` | Запустите установщик, затем откройте приложение из меню «Пуск». Установка для вашей учётной записи. |
| Ubuntu 22.04+ или совместимый Debian, Intel/AMD 64 бит | `camoufox-pm-linux-x86_64.deb` | Откройте системным установщиком программ, затем запустите из меню приложений. |

Если в Windows отсутствует Microsoft WebView2, установщик загрузит его
через официальный компонент Microsoft; для этого нужен интернет. Если WebView2
по-прежнему недоступен, проверьте соединение или обратитесь к администратору,
затем нажмите **Retry**. **Cancel** останавливает установку до замены существующих
файлов менеджера.

Для Linux также есть переносимый `.tar.gz`: распакуйте папку целиком и откройте
исполняемый файл `camoufox-pm`. Папка `_internal` должна остаться рядом с ним.
Вариант `.deb` предпочтительнее: он указывает необходимые системные графические
библиотеки. Другие дистрибутивы Linux пока не проверены.

Установщики проекта не подписаны, сборки macOS не проходят нотариализацию.
Сертификаты и нотариализация не планируются и не являются условиями выпуска.
Скачайте файл из официального релиза и сравните SHA-256 с контрольной суммой
перед решением об открытии. Возможны предупреждения Gatekeeper в macOS или
SmartScreen в Windows. На служебном компьютере может понадобиться разрешение администратора.
Не отключайте защиту системы. Подробнее: [подпись и ограничения](signing.md).

## Первый профиль

Русский интерфейс и короткая памятка первого запуска появятся в общем релизе
**0.7.0**. Установщики 0.6.0 пока содержат английский и упрощённый китайский.
В новой версии выберите **Language → Русский** внизу боковой панели; выбор языка
также доступен до входа. При доступном локальном хранилище выбор сохраняется.
Язык менеджера не меняет языки отпечатка, часовой пояс, куки и настройки профилей.

1. Откройте **Camoufox Profile Manager**. Данные хранятся отдельно от программы.
2. Нажмите **Install browser** («Установить браузер») в стартовой панели. Для
   первой загрузки нужен интернет. Приложение показывает ход установки и ошибки;
   при сбое повторите попытку. В Settings есть **Retry download**.
3. Нажмите **Create first profile** или **New profile**, задайте понятное имя.
4. Оставьте расширенные настройки фингерпринта по умолчанию. Прокси добавляйте,
   если он у вас уже есть; перед использованием проверьте его.
5. Нажмите **Run**. Откроется отдельное окно Camoufox. Закройте его или нажмите
   **Stop**, когда закончите. Закрытие менеджера также останавливает запущенные
   им окна браузера.

Профиль сохраняет куки, историю и фингерпринт между запусками. Клон по умолчанию
получает другую машину. Генерация нового фингерпринта меняет видимую для сайтов
машину: прочитайте предупреждение перед подтверждением.

В русском интерфейсе соответствующие кнопки называются **Установить браузер**,
**Создать первый профиль**, **Новый профиль**, **Запустить** и **Остановить**.
Если установка не удалась, проверьте интернет, свободное место и права на запись
файлов браузера, затем нажмите **Повторить установку**. Создать профиль можно и
во время загрузки; запуск потребует завершённой установки. После закрытия
стартовой панели установка остаётся в **Настройки → Установка браузера**.

Для прокси выберите протокол и укажите `host:port` в поле **Сервер**, а логин и
пароль — в отдельных полях. SOCKS5 с авторизацией поддерживается. HTTP CONNECT и
HTTPS с TLS до самого прокси — разные протоколы: выбирайте тип, который указал
провайдер. Нажмите **Проверить прокси** перед запуском. Если прокси отвечает, но
не хватает данных геолокации, откройте **Настройки → Установка браузера →
Повторить загрузку**. Подробнее: [протоколы и авторизация](proxy-support.md).

## Резервные копии и восстановление

**Settings → Profile backups → Back up profiles** создаёт архив восстановления.
Сначала остановите профили: запущенные или занятые профили пропускаются и будут
обработаны позже. Сохраните копию вне этого компьютера. **Restore as new profile** восстанавливает
профиль отдельно, сохраняя текущий.

Удалённые профили попадают в **Trash**. **Restore** возвращает профиль.
**Delete permanently** просит ввести его имя и удаляет данные браузера; после
этого нужна заранее сделанная резервная копия. Архивы могут содержать куки,
историю, активные входы на сайты и пароли прокси: архивы не зашифрованы.
Они не включают учётные записи менеджера, его сеансы входа и глобальные настройки.
Для восстановления архива профиля старый ключ не нужен: пароли прокси будут
зашифрованы текущим ключом. Для сохранения всей установки берегите исходную базу
и ключ. По умолчанию автоматические копии создаются каждые 24 часа; сохраняются
семь обычных архивов и две контрольные копии перед обновлением на профиль.
Trash не очищается автоматически; после восстановления расписания остаются на паузе.

**Settings → App updates → Check for updates** проверяет новые релизы на GitHub.
Перед подготовкой обновления остановите профили.
**Back up and prepare update** сначала создаёт резервную копию, затем предлагает
страницу загрузок релиза. Выберите установщик для своего компьютера. Проверяется принадлежность ссылки этому проекту,
а не криптографическая подпись установщика. Скачайте его, закройте
менеджер и установите поверх текущей программы. Приложение пока не заменяет
собственный исполняемый файл автоматически. Если резервное копирование не
удалось, подготовка обновления останавливается.

## Где хранятся данные

Папка не зависит от того, откуда вы запускаете приложение:

| Система | Папка по умолчанию |
| --- | --- |
| macOS | `~/Library/Application Support/Camoufox Profile Manager/` |
| Windows | `%LOCALAPPDATA%\Camoufox Profile Manager\` |
| Linux | `$XDG_DATA_HOME/camoufox-profile-manager/` или `~/.local/share/camoufox-profile-manager/` |

Берегите всю папку: `profiles.db`, данные браузера, резервные копии и
`secret.key`. При первой установке создаётся ключ шифрования; без него
зашифрованные пароли прокси могут стать недоступны. Переустановка программы и
удаление Windows-приложения сохраняют отдельную папку данных. Запуск из исходников
через CLI по-прежнему использует `data/profiles.db`, если не настроен другой путь;
старые данные автоматически в папку настольного приложения не переносятся.

Локальный сервер доступен только на вашем компьютере и выбирает свободный порт.
Сообщение **already open** означает, что нужно переключиться на уже открытое окно.
При ошибке запуска смотрите `desktop.log` в папке данных: оконные сборки пишут туда
вывод программы. Перед публикацией журналов проверьте, нет ли в них личных данных.

## Из исходников (для разработчиков)

Установите [uv](https://docs.astral.sh/uv/) и Node.js 20.9+. Python установит uv.

```bash
git clone https://github.com/polyackiy/camoufox-profile-manager.git
cd camoufox-profile-manager
uv sync --extra desktop
uv run python scripts/build_webui.py
uv run python -m camoufox_pm.desktop
```

В Linux запуск из исходников требует графического backend для pywebview и его
системных библиотек; готовый `.deb` уже включает Qt. Для запуска во вкладке
используйте `uv sync`, соберите интерфейс и выполните `uv run camoufox-pm`.
Подробнее: [CLI](cli.md), [настройки профилей](profile-settings.md).
